# Netz und Gesellschaft

Interaktive Einzelarbeit für Informatik Klasse 9/10 zu den gesellschaftlichen Folgen des Internets:
sechs Stationen (Gesellschaft, soziale Netzwerke, E-Commerce, Wissen und Bildung, Fake News,
Schattenseiten des Internets) mit Experimenten und einem Abschlusstest mit Ergebniskarte und Prüfcode.

- **Einzelarbeit:** https://digitalteaching.github.io/netz-und-gesellschaft/
- **Quellen zur Gruppenarbeit:** https://digitalteaching.github.io/netz-und-gesellschaft/quellen.html
